Cara Menerapkan

Langkah-langkah update project Android Studio

  1. Salin isi tab strings.xml → tempel ke app/src/main/res/values/strings.xml
  2. Salin isi tab colors.xml → tempel ke app/src/main/res/values/colors.xml
  3. Salin isi tab activity_main.xml → tempel ke app/src/main/res/layout/activity_main.xml
  4. Ganti logo: klik kanan folder res → New → Image Asset → pilih logo baru
  5. Rebuild APK: Build → Build APK(s)
